# مراقب همزات PS5 — الشرق المغربي

كيقلب تلقائياً على PS5 بثمن لا يتجاوز 4000 درهم في وجدة، بركان، أحفير، الناظور وتاوريرت، وكيصيفط الإعلان الجديد إلى Telegram بلا تكرار.

## 1) صنع بوت Telegram

1. افتح Telegram وقلب على `@BotFather`.
2. صيفط `/newbot`، اختار الاسم، وخذ **Token**. ما تصيفطوش لأي شخص.
3. افتح البوت الجديد واضغط **Start**.
4. افتح في المتصفح، وبدّل `TOKEN` بالتوكن:
   `https://api.telegram.org/botTOKEN/getUpdates`
5. صيفط أي رسالة للبوت، حدّث الصفحة، وخذ الرقم الموجود في `chat.id`.

## 2) رفع المشروع إلى GitHub

1. دير حساب مجاني في GitHub.
2. أنشئ Repository جديداً **Public** باسم `ps5-deal-watcher`.
3. فك الضغط وارفع **محتويات** مجلد `ps5-deal-watcher` كاملة، بما فيها مجلد `.github`.
4. من المستودع افتح: `Settings` → `Secrets and variables` → `Actions`.
5. أضف سرين:
   - `TELEGRAM_BOT_TOKEN`: التوكن من BotFather.
   - `TELEGRAM_CHAT_ID`: رقم `chat.id`.

## 3) أول اختبار

افتح `Actions` → `PS5 Deal Watcher` → `Run workflow`. من بعد كيخدم كل 10 دقائق تلقائياً. أول تشغيل قد يرسل الإعلانات المطابقة الموجودة حالياً، وبعدها يرسل الجديدة فقط.

## تغيير الثمن والمدن

عدّل `config.json`. الثمن موجود في `max_price_mad` والمدن في `cities`. يمكن إضافة روابط بحث Avito إضافية داخل `search_urls`.

## ملاحظة Facebook Marketplace

Facebook لا يوفر واجهة مجانية رسمية للبحث في Marketplace، ويمنع غالباً متصفحات السحابة أو يطلب تحققاً من الحساب. لذلك النسخة الأساسية تشغل Avito باستقرار أكبر. إضافة Facebook تحتاج جلسة حساب محفوظة وتتوقف عند طلب التحقق؛ لا تضع كلمة المرور داخل GitHub ولا داخل الكود.

## إذا توقف التنبيه

افتح تبويب `Actions` وشاهد آخر تشغيل. مواقع الإعلانات تغير تصميمها أحياناً، وعندها يلزم تحديث طريقة قراءة الصفحة. لا تنشر Token في ملف أو صورة؛ خزّنه دائماً في Secrets.
